Intertia

RPGMaker, Blender, python, C, C++

Overview

A story focused turn based RPG. Involes combat with demons which are manifestation of human emotions, kind of like the demons in warhammer 40k. The main theme discusses how humans, despite knowing they are going down the wrong path, can not stop themselves from doubling down, like a force of nature is pushing them to keep making the same mistakes over and over. Kind of like, Interia.

Key Highlights

  • Automated Gameplay Verification: Bot scripts verifying level collision bounds, character spawn states, and UI inventory triggers.
  • Frame Rate & Performance Profiling: FPS drop detection and memory footprint logging during peak action sequences.
  • Network Latency Simulation: Packet loss and high-ping simulation tools for multiplayer netcode validation.
